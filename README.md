# Sombra del Rey Demonio
los controles son los siguientes
1)con enter puedes iniciar la partida [ENTER]
2)con el espacio puedes lanzar ataques [SPACE]
3)con las flechas puedes avanzar ->
4)con Z colocas una pantalla de menú cuando estas en la partida 
5)en la pantalla de menú que se abre con Z puedes tocar la tecla X para salir a la pantalla de titulo
